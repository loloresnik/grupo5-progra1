# Sistema de Gestión de Inventarios

Trabajo Práctico de Programación 1 — UADE,grupo 5  2C 2026.

## Descripción

Sistema de gestión de inventarios desarrollado en Python. Permite administrar productos, stock, movimientos, proveedores, categorías y ventas, además de generar reportes y estadísticas.

El sistema cuenta con un inicio de sesión que diferencia entre **administrador** y **usuario**. El administrador dispone además de funciones para realizar el alta y baja de empleados.

## Funcionalidades

- Alta, baja, búsqueda, modificación y consulta de productos.
- Gestión de stock y movimientos.
- Gestión de proveedores.
- Gestión y consultas de categorías.
- Registro de ventas.
- Reportes y estadísticas.
- Inicio de sesión con distintos niveles de acceso.
- Alta y baja de empleados.
- Validaciones de datos y control de errores.

## Estructura del proyecto

- `MainP.py`: programa principal y coordinación del sistema.
- `menu.py`: inicio de sesión y menús.
- `gestion_productos.py`: gestión de productos.
- `proveedores.py`: gestión de proveedores.
- `Reporte.py`: reportes y estadísticas.
- `empleados.py`: gestión de empleados y usuarios.

## Tecnologías y conceptos utilizados

- Python
- Listas y diccionarios
- Matrices
- Sets

- `map`, `filter` y `lambda`
